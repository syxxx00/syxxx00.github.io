# 枝析源码运行说明

公开目录提供源码、网页、依赖清单及 Windows 安装和启停入口。

1. 在枝析仓库选择 Code → Download ZIP，完整解压；也可以使用 Git 克隆。
2. 准备 Python 3.12，运行 setup.bat，网页后台依赖安装到项目内的 .venv。
3. 运行 start.bat，在浏览器打开本地工作区。
4. 在右上角“设置”中配置自己的模型，再在提交任务时选择。

模型可使用自己的兼容 API，也可配置本地 GGUF 或 Hugging Face 模型。Python、模型权重、llama.cpp 或相应推理环境按使用方式准备，不随网页依赖自动安装。

网页需通过后台服务使用。详细配置、依赖及安装方法见项目 README；源码运行 ZIP 的说明以相应包内文档为准。
