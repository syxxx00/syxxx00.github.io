## 素材

游戏主图与机制对照来自 2026-10-15 普通 Player 实机：手牌悬停，以及不同轮次中两次释放后的速度与资源状态。局部视图可放大查看完整原图。图像实验选自实际项目。枝析截图由当前产品阅读组件呈现 9B 阶段已保存报告，分别展示阅读开头与来源展开；公开节选与截图对应同一版本。规则推演和管线图按各自用途标注。原图保持像素不变，实验 PNG 移除文本及 EXIF 元数据。
