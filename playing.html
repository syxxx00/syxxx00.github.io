Not So Fast!

试玩指南

Windows 64 位版本。双击 CardGameDemo.exe 开始；分享时复制整个 Player 文件夹。

  1. 从主页进入组牌，点击卡池加牌、点击牌组减牌，悬停阅读完整牌面。牌组至少40张，同名最多4张；保存后可选择本地人机牌组，或在联机房间选择自己的套牌。
  2. 对局中点击自己的手牌，依提示选择目标或选项。速度越高越先结算，同速后放先结算；双方跳过后开始结算，跳过后本回合不能继续出牌。
  3. 悬停可读完整牌面及已选目标关系；指示物图标可查看类型。弃牌区、放逐区和历史可查看已公开内容。
  4. 设置可调音量、全屏/窗口、详情位置及投降。本地人机结束后返回主页；联机结束后仍连接时可返回原房间。

起始生命15，治疗没有固定上限。债务结算或被移除后进入放逐区；单张牌及其连锁处理后的致死会立即结束对局。

自带牌组提供玩法样本，AI用于本地人机试玩。当前支持双人地址联机，不提供账号、匹配或云存档。

双人联机按以下过程使用：

  1. 双方使用同一联机版本，先在自己的组牌页保存合法套牌。首次游玩可先体验教学；联机不会自动启动教学。
  2. 主机从主页进入“联机”，确认端口后点击“创建主机”，再“复制邀请”发给朋友。界面默认端口47464，主机为P1，程序需保持运行。
  3. 加入者为P2，粘贴完整邀请后点击“加入房间”；邀请已包含凭据时，凭据栏留空。也可填写完整IPv4地址:实际端口及房间凭据；凭据是邀请中key=后的内容。只连接本游戏兼容TCP服务，不能使用其他游戏或WebSocket服务地址。请勿省略端口。
  4. 各自选择自己的本地已保存套牌并勾选“准备”。更换套牌会取消本人准备；双方连接且准备后，由P1点击“开始对局”。主机身份不决定先手，两端自己的手牌均在下方，P1／P2身份保持。
  5. 按原规则完成对局，或从设置确认本人投降。结果显示结束后点击“返回房间”；双方都返回后重新准备，P1即可开始下一局。对方套牌只在主机保留本次房间的临时副本，不写进自己的存档；房间界面只显示选牌／准备状态。
  6. 短断线时保留游戏窗口，原P2会自动尝试恢复原席位约3分钟；原主机必须仍运行并保留内存原局。恢复继续原局／原待答，不重新出牌。超时、关闭房间或主机退出会明确中断，断线不会自动判负；主机重启后不能续接原局。
  7. 首次连接失败可检查地址、端口与凭据后“重试连接”。“离开房间”关闭连接，“离房返回”关闭连接并回主页；需要恢复原局时不要退出程序或离房。本地套牌不受这些操作影响。

连接地址必须能被朋友访问。同一局域网可用主机IPv4；公网、VPN或玩家自行配置的TCP隧道要提供对应可达端点，邀请自动取得的本机地址未必适用。程序不会自动穿透NAT或配置防火墙／路由器。传输为普通TCP，没有TLS加密；可通过玩家自行配置的VPN／加密隧道连接。P1是权威主机，实际持有完整对局状态及双方选中套牌；合法界面投影不代表向主机进程隐藏这些信息。

牌组存档和运行日志位于 %USERPROFILE%\AppData\LocalLow\DefaultCompany\CardGameIndependent_20261012\。已有牌组会保留；坏存档须明确选择“备份并恢复”才恢复内置牌组，原件备份留在同目录。请勿删除存档来绕过错误。

反馈时记录包名、回合/牌名、操作前状态、实际操作和预期/实际结果。遇到卡住、无法点击、存档或规则问题，请保留截图与 Player.log；再次启动可能改写日志，先复制需要的那份。
